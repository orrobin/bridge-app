# Corpus sources ledger

Every item ingested into the knowledge base must have a row here with a license tag.
`scripts/ingest_corpus.py` (Epic 4) refuses to load any file in `corpus/content/` that isn't
listed here with a license -- see SAD Phase 3.1 ("license-first ingestion").

All entries below are original explainers written for Bridge, informed by publicly described,
non-proprietary psychology concepts (attachment theory, Gottman-style interaction research,
nonviolent communication) but not reproductions of any copyrighted book, article, or course.
Where a concept traces to a specific named line of research, that's noted for the user's
awareness, not as a claim that this text is that source's own words.
